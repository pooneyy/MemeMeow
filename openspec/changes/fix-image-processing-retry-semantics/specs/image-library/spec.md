## ADDED Requirements

### Requirement: 选中图片的完整重试必须执行全部已启用阶段
当用户对选中的图片发起完整重试时，系统 MUST 为每张没有活动处理的图片创建新的父 Job revision，并将视觉分析、Agent、文本向量以及本次启用的自动重命名全部列入执行范围。已有产物仍然有效不得成为跳过这些阶段的理由。未启用的可选阶段 MUST 明确记录为本次不执行，且不得创建对应叶子 Task。

#### Scenario: 完整重试已有全部产物的图片
- **WHEN** 用户选择一张视觉、Agent、自动重命名和文本向量均已完成的图片，并启用自动重命名后提交完整重试
- **THEN** 系统创建新的父 Job revision
- **AND** 新 Job 依次创建并执行四个新的阶段 Task，不复用已有产物跳过任何阶段

#### Scenario: 完整重试未启用自动重命名
- **WHEN** 用户对图片提交完整重试且本次未启用自动重命名
- **THEN** 系统计划执行视觉、Agent 和文本向量阶段
- **AND** 自动重命名明确记录为本次未启用，不创建自动重命名 Task

### Requirement: 修复所有未就绪必须逐图固定最小修复范围
“修复所有未就绪” MUST 由服务端在当前 scope 内枚举图片，并在每张图片的父 Job 创建时根据当前产物、阶段结果、本次处理选项和直接依赖固定修复范围。已经就绪且不受本次修复影响的阶段 MUST 不执行；计划一旦创建，Worker MUST NOT 因后续缓存检查扩大或缩小该范围。没有需要修复阶段的图片 MUST 不创建父 Job。

重新生成视觉结果本身不会使仍匹配当前图片和配置的 Agent 语境或文本语义结果失效，因此只有视觉未就绪时 MUST 只修复视觉；视觉结果仍可以作为以后执行 Agent 时必须就绪的前置条件。Agent 重新执行可能改变语境，因此 Agent 未就绪时 MUST 同时计划执行 Agent、启用的自动重命名和文本向量。只有自动重命名为 warning 时 MUST 只修复自动重命名。只有文本向量未就绪时 MUST 只修复文本向量。多个问题同时存在时，修复范围 MUST 是这些规则所需阶段的合集，并继续遵守固定阶段顺序。

#### Scenario: 只有自动重命名为 warning
- **WHEN** 图片的视觉、Agent 和文本向量均就绪，自动重命名为 warning，且本次启用自动重命名
- **THEN** 系统为该图片创建只计划执行自动重命名的修复 Job
- **AND** 不创建视觉、Agent 或文本向量 Task

#### Scenario: 只有 Agent 未就绪
- **WHEN** 图片的视觉结果有效，但 Agent 结果未就绪，且本次启用自动重命名
- **THEN** 系统计划执行 Agent、自动重命名和文本向量
- **AND** 系统不执行视觉阶段

#### Scenario: 只有视觉未就绪
- **WHEN** 图片只有视觉结果缺失或过期，其他结果仍与当前图片和输入匹配
- **THEN** 系统只计划执行视觉阶段
- **AND** 不创建 Agent、自动重命名或文本向量 Task

#### Scenario: 当前 scope 已全部就绪
- **WHEN** 服务端枚举后没有任何图片存在需要修复的已启用阶段
- **THEN** 系统返回目标数为零的成功结果
- **AND** 不创建父 Job 或叶子 Task

### Requirement: 批量修复必须只拒绝发生活动冲突的图片
批量修复 MUST 逐图检查和创建父 Job。某张图片存在任何活动图片处理时，系统 MUST 只拒绝该图片并返回稳定原因；其他图片 MUST 继续处理，已创建的 Job 不得因为后续图片冲突或失败而回滚。

#### Scenario: 批量修复中只有一张图片正在处理
- **WHEN** 批量修复枚举到图片 A 正在处理，而图片 B 和图片 C 可以修复
- **THEN** 系统将图片 A 记录为 `image_processing_active`
- **AND** 系统继续为图片 B 和图片 C 创建各自的修复 Job
- **AND** 响应逐图说明三张图片的结果和原因

#### Scenario: 选中多张图片完整重试时部分冲突
- **WHEN** 用户对选中的图片 A、B、C 发起完整重试，图片 A 正在处理而图片 B 和图片 C 空闲
- **THEN** 系统将图片 A 记录为 `image_processing_active`
- **AND** 系统继续为图片 B 和图片 C 创建强制执行全部已启用阶段的父 Job revision
- **AND** 不因图片 A 的冲突回滚图片 B 或图片 C
